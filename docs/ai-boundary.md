# AI Boundary

AI can be useful at the interpretation boundary, where documents and unstructured text need assistance. Conceptual uses include:

- Reading invoices
- Extracting candidate fields from documents
- Identifying a likely document type
- Proposing a category
- Suggesting a match for an ambiguous document and transaction
- Summarizing uncertainty for the user

These are proposed optional assistance patterns, not claims that every one is implemented today.

## Non-negotiable boundary

> AI OUTPUT != ACCOUNTING TRUTH

An AI result is evidence or a suggestion. It must be accepted by deterministic logic or human review before it affects an accounting entry. The verified private-application direction is that future AI remains optional and cannot modify an accounting entry without user validation.

AI is therefore an augmentation layer around the accounting core, not a replacement for explicit rules, traceability, or human authority.
